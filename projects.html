FastCV PK

ATS Resume Builder & Biodata Maker · Next.js · 2026

The Vision

FastCV PK was created as Pakistan's premier free online resume builder. The target was to offer a frictionless ATS-friendly CV builder and custom Matrimonial Biodata generator optimized specifically for regional users, without heavy templates or complex design editors.

The Build

Built as a Next.js 14 web application using Tailwind CSS for UI and Cloud Firestore for document storage. Deployed at the edge, it integrates Google Gemini API to write and polish job descriptions, and renders print-ready, high-resolution A4 PDFs instantly in the browser using jsPDF.

The Outcome

The application has generated thousands of resumes since launch, offering a fully mobile-responsive interface that allows job-seekers to create and download water-mark-free, ATS-friendly professional resumes in seconds.

RishtaGPT

AI Matrimonial Bio Maker · Next.js · 2026

The Vision

RishtaGPT was designed to simplify matrimonial profiling by generating elegant, culturally grounded bio-datas. Users require a quick, secure, and respectful generator to draft personal portfolios in multiple styles and languages.

The Build

A sleek, responsive Next.js application that leverages Gemini AI models. It accepts basic user input and outputs structured, formal descriptions in Urdu, English, and Roman Urdu. It offers 5 distinct tones (Traditional, Modern, Poetic, Professional, Detailed) and instant card image generation.

The Outcome

A highly viral utility in the regional space, enabling users to generate dignified profiles and share them directly on WhatsApp. The site operates with 100% security and zero client-side caching of sensitive images.
